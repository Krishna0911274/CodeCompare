# CodeCompare

CodeCompare is a web-based online code compiler and code comparison platform built with Django.

## Features

- Run code online
- Support multiple programming languages
- Single code execution mode
- Compare two code snippets
- Monaco Editor integration
- Save code
- Update saved code
- Code history
- Open saved programs
- Delete saved programs
- User authentication
- Dockerized deployment

## Tech Stack

- Python
- Django
- JavaScript
- HTML
- CSS
- Bootstrap
- Monaco Editor
- Docker
- Git & GitHub
